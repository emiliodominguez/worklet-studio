# Changelog

## architecture-worklet 0.1.0

An explorable concrete atrium with four gallery levels, bridges, stair treads, a suspended bronze light sculpture and a reflecting pool. CSS properties control the camera, daylight and floor separation. Pointer and keyboard helpers include cleanup and reduced-motion handling.

The studio now includes 13 worklets, 46 presets and a dedicated atrium demo with a camera tour. CodePen demos load the published npm packages. The public playground is deployed through GitHub Pages.

## particles-worklet 1.1.0

Stable seeded generation; smooth CSS-driven motion; spatially indexed, bounded connections; configurable glow, hue, drift, and background; defaults and numeric input limits; standalone minified entry and typed optional loader. Original CSS names retained. Optional three-arm spiral galaxy layout with a luminous center.

## cursor-worklet 1.1.0

Six animated materials: expanding/fading legacy ripples, orbital halos, spectral silk ribbons, tapered comets, sculpted plasma, and chromatic glass lenses. CSS-color and legacy RGB support; zero coordinates; configurable bloom, twist, and press compression. Typed pointer helper with smoothing, bounded history, speed, reduced-motion behavior, hidden-document suspension, and complete cleanup. SSR-safe optional loader. Original CSS names retained.

## New 0.1.0 packages

Aurora ribbons, generative flow fields, liquid ripple interference, iridescent foil, curved water caustics, gravitational vortices, and terrain contours. Shared CSS time, hue, intensity, and seed controls, with deterministic rendering and bounded work. Flow fields now have brighter tapered threads; iridescence adds reflective highlights and finer gradients.

Vortex realism pass: replace the folded orbital sheet with a thin accretion disk, circular shadow, lensed upper/lower arcs, hotter inner gas, and asymmetric emission. Add disk opening and an Ember disk preset; preserve the existing paint name and controls.

## Studio

Turborepo, twelve independently packable packages, 42 interactive presets, a dedicated eight-preset cursor picker, SVG icons, mobile layout, reduced-motion behavior, visibility pausing, code recipes, full screen, and share links. Original npm source retained for provenance. Unit, browser, and isolated-package checks plus CI configuration.

## Immersive material pass

All twelve effects gain material or depth work: shaded three-dimensional aurora ribbons; depth-weighted particles and flow trails; reflected liquid wave normals; thin-film foil; focused underwater light; accretion bloom and background stars; occluding, shaded mountain ridges; fractal nebula emission and absorption; merging three-dimensional metaballs; crystal highlights. Glass, plasma, orbit, and silk cursors gain shaded surfaces while the original animated ripple contract remains intact.

Eleven non-cursor loaders export `attachView` for eased pointer lighting and parallax with reduced-motion handling and cleanup. Recipes include the appropriate helper. No Three.js, WebGL, canvas element, or image assets are added to the showcase.

New packages: nebula-worklet, metaballs-worklet, and kaleidoscope-worklet. Batch npm release scripts include full validation, exact tarball rehearsal, registry/version/ownership preflight, resumability, and a persistent progress report.
